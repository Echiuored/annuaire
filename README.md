# 📇 Annuaire du Personnel

Application web de gestion d’un annuaire du personnel développée en PHP avec MySQL.

---

## 🚀 Fonctionnalités

- 🔐 Authentification utilisateur
- 👥 Liste des personnels
- ➕ Ajout d’un personnel
- ✏️ Modification des informations
- 🗑️ Suppression d’un personnel
- 🔍 Recherche
- 📄 Export PDF
- 🌤️ Affichage météo dans le bandeau

---

## 🛠️ Technologies utilisées

- PHP (PDO)
- MySQL
- HTML / CSS
- FPDF (génération PDF)
- API OpenWeather (météo)
- Laragon (environnement local)
